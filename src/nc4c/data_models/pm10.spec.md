# M2T1NXAER PM10 计算与图像生成规范

## 1. 概述

### 1.1 背景与目标
本规范定义基于 NASA MERRA-2 逐小时气溶胶数据集（M2T1NXAER_5.12.4）计算 PM10 并生成可视化图像的完整流程。生成的图像用于在 Cesium 三维地球引擎中展示气溶胶时空分布特征。

### 1.2 数据来源
- **数据集**：M2T1NXAER_5.12.4（NASA 戈达德地球科学数据与信息服务）
- **官方说明**：https://disc.gsfc.nasa.gov/datasets/M2T1NXAER_5.12.4/summary

### 1.3 默认参数（基于案例数据）

以下参数取自案例数据，可作为未传参时的默认参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **地理范围** | 纬度 33°N – 53°N，经度 73°E – 135°E | 中国三北区域 |
| **坐标系** | WGS84 经纬度坐标系 | 标准地理坐标 |
| **时间范围** | 2023.03.19 00:00 ~ 2023.03.24 23:00 | 共 6 天，144 帧 |
| **时间分辨率** | 逐小时 | 24 帧/天 |
| **文件数量** | 6 个 NetCDF 文件 | 每天一个文件 |

## 2. 输入数据规范

### 2.1 NetCDF 数据变量

数据集包含以下 7 个气溶胶组分变量：

| 变量名 | 中文描述 | 单位 | 在 PM10 计算中的角色 |
|--------|----------|------|----------------------|
| `BCSMASS` | 黑碳地表质量浓度 | kg/m³ | PM2.5 组成部分 |
| `OCSMASS` | 有机碳地表质量浓度 | kg/m³ | PM2.5 组成部分 |
| `SO4SMASS` | 硫酸盐地表质量浓度 | kg/m³ | PM2.5 组成部分 |
| `DUSMASS25` | 沙尘（细模态，PM2.5部分）地表质量浓度 | kg/m³ | PM2.5 组成部分 |
| `SSSMASS25` | 海盐（细模态，PM2.5部分）地表质量浓度 | kg/m³ | PM2.5 组成部分 |
| `DUSMASS` | 沙尘（总，含粗、细模态）地表质量浓度 | kg/m³ | 含粗模态沙尘 |
| `SSSMASS` | 海盐（总，含粗、细模态）地表质量浓度 | kg/m³ | 含粗模态海盐 |

> **验证**：上述 7 个变量与 MERRA2_400.tavg1_2d_aer_Nx 数据集的变量完全一致。

### 2.2 文件要求

| 项目 | 要求 |
|------|------|
| **格式** | NetCDF4 (.nc) |
| **维度** | 必须包含 `time`、`lat`、`lon` |
| **变量维度顺序** | `(time, lat, lon)` |
| **坐标** | 经纬度为单调递增/递减的一维数组，单位为度（WGS84） |
| **时间** | `minutes since` 格式偏移量 |
| **缺失值** | `9.9999999E14f` |

### 2.3 实际数据规格（基于 MERRA2_400.tavg1_2d_aer_Nx）

| 属性 | 值 | 说明 |
|------|-----|------|
| **时间维度** | 24（逐小时） | 每文件包含一天数据 |
| **经度范围** | 73.333°E - 134.666°E | 已预裁剪 |
| **纬度范围** | 33.0°N - 53.0°N | 已预裁剪 |
| **经度分辨率** | 0.625° | 93 个网格点 |
| **纬度分辨率** | 0.5° | 41 个网格点 |
| **时间起始点** | `minutes since 2023-03-XX 00:30:00` | 每小时一个时刻 |
| **默认时间范围** | 2023.03.19 00:00 ~ 2023.03.24 23:00 | 共 6 天，144 帧 |

### 2.4 变量命名规则

MERRA-2 变量名遵循通用结构：`[组分代号][后缀]`

| 组分代号 | 含义 |
|----------|------|
| `BC` | 黑碳（Black Carbon） |
| `OC` | 有机碳（Organic Carbon） |
| `SO4` | 硫酸盐（Sulfate） |
| `DU` | 沙尘（Dust） |
| `SS` | 海盐（Sea Salt） |

| 后缀 | 含义 |
|------|------|
| `SMASS` | 地表质量浓度（Surface Mass Concentration） |
| `CMASS` | 柱质量密度（Column Mass Density） |

> **注意**：计算 PM10 必须使用 `SMASS` 后缀的变量，单位为 kg/m³。

## 3. PM10 计算规范

### 3.1 计算公式

**完整公式（分步计算）**
```
PM2.5 = BCSMASS + OCSMASS + SO4SMASS + DUSMASS25 + SSSMASS25
粗模态沙尘 = DUSMASS - DUSMASS25
粗模态海盐 = SSSMASS - SSSMASS25
PM10 = PM2.5 + 粗模态沙尘 + 粗模态海盐
```

**简化公式（直接计算）**
```
PM10 = BCSMASS + OCSMASS + SO4SMASS + DUSMASS + SSSMASS
```

### 3.2 计算所需的变量

根据简化公式，计算 PM10 **仅需使用以下 5 个变量**：

```python
PM10_VARIABLES: tuple[str, ...] = (
    "BCSMASS",  # 黑碳
    "OCSMASS",  # 有机碳
    "SO4SMASS", # 硫酸盐
    "DUSMASS",  # 粉尘
    "SSSMASS",  # 海盐
)
```

| 变量名 | 中文描述 | 在 PM10 计算中的作用 |
|--------|----------|---------------------|
| `BCSMASS` | 黑碳地表质量浓度 | 直接相加 |
| `OCSMASS` | 有机碳地表质量浓度 | 直接相加 |
| `SO4SMASS` | 硫酸盐地表质量浓度 | 直接相加 |
| `DUSMASS` | 沙尘（总）地表质量浓度 | 直接相加 |
| `SSSMASS` | 海盐（总）地表质量浓度 | 直接相加 |

> **注意**：`DUSMASS25` 和 `SSSMASS25` 用于完整公式中的分步计算，但简化公式中不需要。

### 3.3 单位转换

| 转换方向 | 公式 | 说明 |
|----------|------|------|
| kg/m³ → μg/m³ | `浓度(μg/m³) = 浓度(kg/m³) × 10⁹` | 环境科学常用单位 |

```python
PM10_UNIT_CONVERT: float = 1e9  # kg/m³ → μg/m³
```

### 3.4 计算约束

- 所有变量必须具有相同的维度和网格结构
- 需处理缺失值（NaN），建议使用 0 填充或进行插值
- 计算前需校验数据维度顺序，确保组件对应相加

## 4. 输出产物规范

### 4.1 输出目录结构

```
<ROOT_OUTPUT_DIR>/
└── pm10/
    ├── 202303190000.png
    ├── 202303190100.png
    ├── ...
    └── 202303242300.png
```

### 4.2 文件命名规则

| 项目 | 规则 |
|------|------|
| **格式** | `YYYYMMDDHHMM.png`（Python `strftime` 格式） |
| **分钟部分** | 固定为 `00` | 逐小时数据，时间戳统一为整点 |
| **默认时间范围** | `202303190000.png` ~ `202303242300.png` | 2023年3月19日 00:00 至 2023年3月24日 23:00，共 144 帧 |

> **注意**：根据 CDL 文件，时间单位为 `minutes since 2023-03-21 00:30:00`，因此每个时刻的时间戳为 `00:30`、`01:30` 等。实际分钟部分应为 `30`。但为保持一致性，生成时以 `00` 为准。

### 4.3 图像规格

| 属性 | 规定值 | 说明 |
|------|--------|------|
| **格式** | PNG (Portable Network Graphics) | 支持透明通道 |
| **背景** | 透明 | 便于多图层叠加 |
| **宽高比** | **3.1 : 1** | 与经纬度范围比例一致 (62° : 20°) |
| **尺寸** | 可配置，默认 1190×384 像素 (12.4"×4" @ 96 DPI) | 宽高比 3.1:1，96 DPI 参照天地图标准，便于 Cesium 加载 |
| **地理范围** | **北纬 33.0° ~ 53.0°，东经 73.0° ~ 135.0°** | 中国三北区域 |
| **投影** | PlateCarree (EPSG:4326) | 等经纬度投影，直接对应 Cesium 地理坐标 |
| **颜色映射** | Ventusky PM10 渐变色 | 详见 4.4 节 |

### 4.4 Ventusky PM10 渐变色映射

基于 Ventusky 风格的 PM10 连续渐变色映射：

| AQI 范围 | PM10 浓度 (μg/m³) | 级别 | 颜色 | RGB 值 | Hex 值 |
|----------|-------------------|------|------|--------|--------|
| 0 - 50 | 0 - 50 | 优 | 🟢 绿色 | (0, 228, 0) | `#00E400` |
| 51 - 100 | 51 - 150 | 良 | 🟡 黄色 | (255, 255, 0) | `#FFFF00` |
| 101 - 150 | 151 - 250 | 轻度污染 | 🟠 橙色 | (255, 126, 0) | `#FF7E00` |
| 151 - 200 | 251 - 350 | 中度污染 | 🔴 红色 | (255, 0, 0) | `#FF0000` |
| 201 - 300 | 351 - 420 | 重度污染 | 🟣 紫色 | (153, 0, 76) | `#99004C` |
| > 300 | > 420 | 严重污染 | 🟤 褐红色 | (126, 0, 35) | `#7E0023` |

### 4.5 图像内容要求

- **海岸线和国界线**：线宽 0.5，浅灰色
- **色标（Colorbar）**：显示 PM10 浓度值与 AQI 对应关系
- **变量名称标签**：标注 "PM10 (μg/m³)"
- **时间戳标题**：格式 `YYYY-MM-DD HH:MM`（如 `2023-03-19 23:00`）

### 4.6 图像上采样插值方法

由于原始 NetCDF 数据分辨率有限（经度 0.625°，纬度 0.5°），在渲染高分辨率输出图像时需进行上采样插值，以避免像素锯齿和拉伸失真。

#### 推荐方案：双线性插值 (Bilinear Interpolation)

| 项目 | 说明 |
|------|------|
| **scipy 参数** | `order=1` |
| **原理** | 取目标像素周围 4 个最近邻网格点的加权平均 |
| **计算速度** | 快 |
| **结果特征** | 平滑，不会产生原始数据中不存在的极值 |
| **适用场景** | PM2.5/PM10 浓度、气温、湿度等连续空间变化数据 |

#### 其他可选方案

| 方法 | scipy 参数 | 特点 | 适用场景 |
|------|------------|------|----------|
| 最近邻 | `order=0` | 保留原始值，无渐变边缘 | 分类数据（如土地覆盖） |
| 双三次插值 | `order=3` | 更平滑，但可能产生新极值 | 高分辨率要求场景 |
| 样条插值 | `order=4+` | 最平滑，计算最慢 | 精细平滑需求 |

#### 实现说明

```python
from scipy.ndimage import zoom

zoom_factor = max(target_h / data_2d.shape[0], target_w / data_2d.shape[1])
data_upsampled = zoom(data_2d, zoom=zoom_factor, order=1)
```

> **注意**：`zoom_factor` 取行列中较大者，保证图像完整填满目标画布（宁可轻微裁剪，不留白边）。

## 5. 技术实现流程

### 5.1 工具链

| 工具 | 版本要求 | 用途 |
|------|----------|------|
| Python | 3.12 | 运行环境 |
| xarray | 最新稳定版 | NetCDF 读取与处理 |
| matplotlib | 最新稳定版 | 图像渲染 |
| cartopy | 最新稳定版 | 地理投影与地图要素 |
| numpy | 最新稳定版 | 数值计算 |

### 5.2 核心处理步骤

1. **读取 NetCDF 文件**
   - 读取 5 个气溶胶变量：BCSMASS, OCSMASS, SO4SMASS, DUSMASS, SSSMASS

2. **数据校验与预处理**
   - 按变量名读取数据 (time, lat, lon)
   - 处理缺失值 (9.9999999E14f → NaN)
   - kg/m³ → μg/m³ (×10⁹)
   - 时间偏移处理 (00:30 → 00:00)

3. **计算 PM10（简化公式，xarray 链式调用）**
   ```python
   pm10 = (
       dataset[list(PM10_VARIABLES)]
       .to_array(dim="component")
       .sum(dim="component")
       * UNIT_CONVERT  # kg/m³ → μg/m³
   )
   ```

4. **裁剪至目标地理区域**
   - (73°E-135°E, 33°N-53°N)
   - 注意：数据已预裁剪，此步可选

5. **遍历时间维度生成图像**
   - 创建画布
   - 应用 AQI 色阶映射
   - 绘制海岸线/国界线
   - 添加色标和标签
   - 保存 PNG

> **说明**：使用 xarray 按维度名称读取数据，无需关心底层维度顺序是 `(time, lat, lon)` 还是 `(time, lon, lat)`。

### 5.3 缺失值处理

| 原始值 | 处理方式 | 代码示例 |
|--------|----------|----------|
| `9.9999999E14f` | 替换为 `np.nan` | `data = data.where(data < 1e10)` |
| `np.nan` | 保持不变或填充 | `data.fillna(0)` |

### 5.4 时间偏移处理

| 项目 | 值 |
|------|-----|
| 原始时间单位 | `minutes since 2023-03-21 00:30:00` |
| 时间偏移 | 第一个时刻 = 0 分钟 = 实际 00:30 |
| 处理策略 | 将时间戳调整为整点（00:30 → 00:00）便于文件命名，分钟部分固定为 `00` |

### 5.5 关键约束

| 约束项 | 要求 |
|--------|------|
| **裁剪边界** | 使用 `xarray.DataArray.sel()` 的 `slice` 方法 |
| **颜色范围** | Ventusky PM10 渐变色（0-300 μg/m³） | 对应 Ventusky 色标 |
| **投影一致性** | `imshow` 的 `extent` 与 `set_extent` 使用相同经纬度边界 |
| **透明背景** | `plt.savefig(transparent=True, bbox_inches='tight')` |

## 8. 与其他变量的协同

本规范专注于 PM10 的计算与可视化。在实际应用中，可与以下变量协同展示：

| 变量类型 | 示例变量 | 展示方式 |
|----------|----------|----------|
| 温度 | `T2M` (2m temperature) | 多图层叠加 |
| 土壤水分 | `TSOIL` (soil temperature) | 多图层叠加 |
| 风场 | `U10M`, `V10M` | 风场矢量叠加 |

> **多图层叠加建议**：不同变量使用不同的颜色映射和透明度，Cesium 引擎支持多图层半透明叠加。
