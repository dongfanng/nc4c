# Low Vegetation Type 数据处理规范

## 1. 数据源

- **来源**: ERA5-Land 低植被类型数据
- **变量**: `tvl` (Type of low vegetation)
- **长名称**: Type of low vegetation
- **单位**: `~` (无量纲，分类数据)
- **维度**: `(time, latitude, longitude) = (1, 201, 621)`
- **时间**: 1996-01-01 (不变数据，只需处理一次)
- **来源说明**: ECMWF IFS GRIB Code table 4.234

## 2. 植被类型分类定义

依据 ECMWF GRIB Code table 4.234 - Low Vegetation (tvl):

| ID | 英文名称 | 中文含义 | 中国区域分布 |
|----|----------|----------|--------------|
| 0 | No vegetation | 无植被 | 占 18.50% |
| 1 | Crops, Mixed farming | 农田/混合农业 | 占 22.02% |
| 2 | Grass | 草地 | 占 25.83% |
| 7 | Tall grass | 高草 | 极少 |
| 9 | Tundra | 苔原 | 占 1.94% |
| 10 | Irrigated crops | 灌溉农田 | 占 6.20% |
| 11 | Semidesert | 半荒漠 | 占 24.32% |
| 13 | Bogs and marshes | 沼泽/湿地 | 占 0.40% |
| 16 | Evergreen shrubs | 常绿灌木 | 占 0.33% |
| 17 | Deciduous shrubs | 落叶灌木 | 占 0.46% |
| 20 | Water and land mixtures | 水陆混合 | 数据中无分布 |

> **说明**: 其他类型 (3,4,5,6,18,19) 属于高植被；0=无植被；8=荒漠；12=冰盖/冰川；14=内陆水体；15=海洋
>
> **来源**: <https://codes.ecmwf.int/grib/param-db/29>

## 4. 处理流程

### 4.1 预处理

1. **读取数据**: 使用 xarray 打开 NetCDF 文件
2. **范围裁剪**: 可选裁剪至指定经纬度范围
3. **缺失值处理**: 本数据集无缺失值

### 4.2 数值处理

- **取整**: 将浮点数值四舍五入到最近的整数类别 (0, 1, 2, 7, 9, 10, 11, 13, 16, 17, 20)

### 5.2 数值范围

色图使用离散分段映射，边界计算:
```
bound[i] = (gradient[i-1].value + gradient[i].value) / 2
bound[0] = gradient[0].value - 0.5
bound[last] = gradient[last].value + 0.5
```
