# Total Precipitation 规范

## 数据源

- **来源**: ERA5-Land
- **变量**: tp
- **长名称**: Total precipitation
- **单位**: m
- **维度**: (valid_time, latitude, longitude)

## 处理

- **公式**: 直接使用 `tp` 变量值
- **单位转换**: m → mm (= value × 1000)
- **缺失值处理**: 3.4028234663852886E38 → np.nan
