# Soil Type 数据处理规范

## 1. 数据源

- **来源**: ERA5-Land 土壤质地数据
- **变量**: `slt` (Soil type)
- **长名称**: Soil type
- **单位**: `~` (无量纲，分类数据)
- **维度**: `(time, latitude, longitude) = (1, 201, 621)`
- **时间**: 2013-11-29 (不变数据，只需处理一次)
- **来源说明**: ECMWF IFS 土壤类型 (基于 FAO 土壤质地数据集)

## 2. 土壤质地分类定义

依据 ECMWF IFS 官方定义 (基于 FAO 土壤质地数据集):

| ID | 英文名称 | 中文含义 | 推荐颜色 | HEX | 说明 |
|----|----------|----------|----------|-----|------|
| 0 | No data/Water | 无数据/非陆地 | 浅蓝灰 | #C9D8E8 | 海洋/湖泊遮蔽，占 8.92% |
| 1 | Coarse | 粗质，砂土 | 浅黄 | #F5DEB3 | 砂质、保水性低 |
| 2 | Medium | 中质，壤土 | 棕黄 | #C8A96E | 最主要类型，占 48.97% |
| 3 | Medium-fine | 中细质 | 赭棕 | #A0785A | 占 28.55%，中国广泛分布 |
| 4 | Fine | 细质，粘土 | 深红棕 | #7B3F00 | 保水性高，粘土 |
| 6 | Organic | 有机质土 | 深橄榄绿 | #4A5C2F | 高持水量，泥炭/有机土 |

## 4. 处理流程

### 4.1 预处理

1. **读取数据**: 使用 xarray 打开 NetCDF 文件
2. **范围裁剪**: 可选裁剪至指定经纬度范围
3. **缺失值处理**: 本数据集无缺失值

### 4.2 数值处理

- **取整**: 将浮点数值四舍五入到最近的整数类别 (0, 1, 2, 3, 4, 6)

## 5. 可视化

### 5.1 色图配置

使用分类颜色映射，每种土壤质地对应一种颜色：

| ID | 土壤质地 | 颜色 | HEX | 视觉含义 |
|----|----------|------|-----|----------|
| 0 | 水体 (Water) | 浅蓝灰 | #C9D8E8 | 海洋/湖泊 |
| 1 | 粗质/砂土 (Coarse) | 浅黄 | #F5DEB3 | 砂质 |
| 2 | 中质/壤土 (Medium) | 棕黄 | #C8A96E | 壤土 |
| 3 | 中细质 (Medium-fine) | 赭棕 | #A0785A | 赭石色 |
| 4 | 细质/粘土 (Fine) | 深红棕 | #7B3F00 | 深棕色 |
| 6 | 有机质土 (Organic) | 深橄榄绿 | #4A5C2F | 深绿色 |

### 5.2 数值范围

色图使用离散分段映射，边界计算:
```
bound[i] = (gradient[i-1].value + gradient[i].value) / 2
bound[0] = gradient[0].value - 0.5
bound[last] = gradient[last].value + 0.5
```

### 5.3 输出规格

- **格式**: PNG images
- **分辨率**: 1190×384 @ 96 DPI
- **文件名**: `soil_type_2013-11-29_00-00-00.png` (时间固定为数据时间戳)
- **投影**: WGS84 经纬度坐标系

## 7. 起沙风险分析提示

在沙尘研究中，土壤质地分类对起沙风险评估很重要：

| ID | 质地类型 | 起沙风险 | 说明 |
|----|----------|----------|------|
| 1 | Coarse (砂土) | **高** | 粒径大但粘结力弱，保水性低，易被风蚀 |
| 2 | Medium (壤土) | 中 | 有一定粘结性，黄土高原主体 |
| 3 | Medium-fine | 中低 | 半干旱草原区域 |
| 4 | Fine (粘土) | 低 | 颗粒细，粘结力强，保水性高 |
| 6 | Organic | 低 | 有机质增强土壤稳定性 |
